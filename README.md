# 🎬 DevSecOps Pipeline Project: Netflix Clone on Kubernetes

> **Overview**  
Designed and automated a **CI/CD pipeline** for a full-stack **Netflix Clone application**, using **Jenkins**, **Argo CD**, and **Amazon EKS**. The project integrates **DevOps**, **Security (DevSecOps)**, and **Observability** best practices to demonstrate modern cloud-native software delivery.

## 🚀 Key Highlights

### 🔧 CI/CD with Jenkins

- ✅ Cloned source code from GitHub, then built, tested, and packaged the app
- 🧪 Integrated **SonarQube** for static code analysis and quality gates
- 🐳 Automated **Docker image builds** and pushed to Docker Hub with version tagging
- 🔄 Triggered **Argo CD** deployments via updated Kubernetes manifests
- 📬 Configured **email notifications** for build success/failure alerts

### ☸️ Amazon EKS Deployment

- 🎯 Deployed the Netflix Clone app to **Amazon EKS**, enabling scalable Kubernetes workloads

### 🚢 Continuous Deployment with Argo CD

- 🤖 Automated app deployment on EKS using **Argo CD**, ensuring GitOps alignment

### 📈 Monitoring & Observability

- 📊 Deployed **Prometheus** for resource and cluster monitoring
- 📉 Built live dashboards in **Grafana** to visualize application and cluster health

### 🔐 Security (DevSecOps)

- 🔍 Used **Trivy** to scan container images for vulnerabilities
- 🛡️ Enforced Kubernetes **RBAC**, **Network Policies**, and **Secrets Management**
- 🔐 Managed AWS access with **IAM roles** and least privilege access control

---

## 🎯 Impact

- ⚡ Achieved full CI/CD automation with security and observability built-in
- 🛠️ Reduced deployment friction and manual overhead
- 🧪 Ensured code quality, runtime security, and real-time infrastructure insights
- 📦 Delivered a production-ready, secure, and scalable Netflix Clone application using modern **DevSecOps pipelines**
